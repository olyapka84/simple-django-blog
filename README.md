# Simple Django Blog

A small test blog created during a Django course.  
The project demonstrates basic concepts of Django — models, views, templates, and routing.

## Features
- Create and view blog posts  
- Basic templates and URL routing  
- SQLite database for local testing  

## Tech stack
- Python  
- Django  
- HTML  

## How to run
```bash
python manage.py runserver
```

Then open in your browser:  
http://127.0.0.1:8000/
